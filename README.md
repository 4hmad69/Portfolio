# 🚀 Ahmad Raza - 3D AI & Backend Developer Portfolio Website

A high-performance, immersive **3D portfolio website** built with **React**, **TypeScript**, **Three.js**, **GSAP**, and **WebGL**, customized for **Ahmad Raza**.

## ✨ Highlights

- **Interactive 3D / WebGL Experience**: Immersive, fluid 3D character and environment powered by **Three.js** and **React Three Fiber**.
- **Modern Tech Stack**: Strict type safety with **TypeScript**, lightning-fast builds with **Vite**, and responsive layouts.
- **Premium Animations**: Super smooth scrolling, text highlights, and transitions powered by **GSAP (GreenSock)**.
- **Interactive About Section**: Dynamic word highlight and hover effects.
- **Classic Chess Game**: Fully operational AI chess game engine (RedoxChess) built directly into the site.

- **Frontend Core**: React, TypeScript, HTML5, CSS3, ESNext
- **3D Modeling & Animation**: Three.js, React Three Fiber, Draco Decoders, GSAP
- **Packaging & Build Tools**: Vite, PostCSS, ESLint, TypeScript Compiler

## ⚡ Deployment on Vercel

Hosting this portfolio on Vercel takes less than 2 minutes. Follow these simple steps:

### Step 1: Sign up / Log in to Vercel
1. Go to [Vercel](https://vercel.com).
2. Sign up or log in using your **GitHub** account.

### Step 2: Import the Repository
1. On your Vercel Dashboard, click **Add New** and select **Project**.
2. Find the repository named **`Portfolio`** (from your account `4hmad69`) and click **Import**.

### Step 3: Configure Settings
Vercel automatically detects Vite configurations, so you can leave the defaults:
- **Framework Preset**: `Vite`
- **Root Directory**: `./`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

### Step 4: Click Deploy 🚀
1. Click the **Deploy** button.
2. Vercel will build the React + TypeScript app and deploy it online in less than a minute.
3. You will receive a production deployment link (e.g., `portfolio-4hmad69.vercel.app`) which you can also link to a custom domain!

## 🚀 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/4hmad69/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
